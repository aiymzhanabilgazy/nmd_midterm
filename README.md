# Personal Task Tracker (Swift Console App)

## Description
A simple console-based task management system written in Swift.  
Users can create, view, update, delete, filter, and sort tasks.

## Features
- Add tasks with priority
- Update task status
- Delete tasks
- Filter by priority
- Sort by priority
- Menu-driven console interface

## Technologies
- Swift
- Xcode

## How to Run
1. Open the project in Xcode
2. Run the project (⌘ + R)
3. Use the console to interact with the menu
